01The three layers

Copying a terabyte is the boring way. omnigate treats migration as a mount, then a smart sync, then a manifest.

LAYER 1

Union mount

Mount the old disk read-only as an overlayfs lower layer under the new OS. Data appears at its new path with zero copy — Steam games launch immediately.

⚡ Migration = a mount entry, not a copy.
LAYER 2

Differential sync

Copy only what changed; skip what's re-downloadable. Reflink-first (btrfs/XFS CoW) means near-instant, no duplicate space.

⚡ 1 TB "migration" becomes a small copy of what matters.
LAYER 3

Declarative manifest

Describe the whole machine — apps, configs, data, library — as a rebuildable manifest. Migration stops being a thing; the machine is the manifest.

⚡ git diff old-manifest omarchy-manifest

02The skip ladder

The world-breaking insight: the fastest transfer is the one you don't do. omnigate moves 20 GB, not 1 TB.

1 · MOUNTData stays where it is; the new OS sees it through overlayfs.
2 · REFLINKCopy-on-write — near-instant, zero extra space.
3 · SKIPSteam games, caches, anything re-downloadable never moves.
4 · DEDUPChunked sync — only novel bytes cross the wire.
5 · HASHblake3 on deltas (12× sha256), trust the reflink.

And the unavoidable transfer gets the full treatment: a Rust core with parallel blake3 hashing and a portable Vulkan-compute GPU backend.

03Quick start

Run on the old machine. Run on the new one. Watch the mount do the heavy lifting.

# On the OLD machine — detect apps + configs, build a package
python3 migrate.py export --os linux --out my-setup.zip

# On the fresh Omarchy box — import (defer rule + compat gate + HM profile)
python3 migrate.py import my-setup.zip --dry-run

# World-breaking: mount the old disk, zero copy
sudo python3 mount.py mount /dev/sdb2 /data/games
python3 mount.py list

Cross-platform by design: omnigate.sh (macOS/Linux), omnigate.ps1 (Windows — built into the OS), and bootstrap.py (all three). Git is the backbone — every machine gets a repo of its migration state.

04The governing rule

omnigate is additive by design. It never fights Omarchy, never duplicates what Omarchy ships, and only carries what your system genuinely adds on top.

Defer to OmarchyIf Omarchy provides it, don't duplicate it. The mapper defers automatically against the Omarchy reference.
Never guessUnknown apps get flagged for review — never auto-mapped.
Zero-copy firstMount before you copy. Copy only what changed.
Rollback alwaysThe old system stays bootable until you say otherwise.
