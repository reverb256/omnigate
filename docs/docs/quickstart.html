01Quick start

Run on the old machine. Run on the new one. Watch the mount do the heavy lifting.

Export — on the OLD machine

# Linux / macOS
./omnigate.sh export --os linux --out my-setup.zip

# Windows
powershell -ExecutionPolicy Bypass -File omnigate.ps1 export --os windows --out my-setup.zip

Detects installed apps, collects configs, builds a git-committable package (machine.json, plan.md).

Import — on the fresh Omarchy box

python3 migrate.py import my-setup.zip --dry-run
# review the plan, then:
python3 migrate.py import my-setup.zip

The defer rule maps apps to Omarchy targets, the compat gate flags unknowns, and the generator emits a Home Manager profile fragment for Reverb-OS.

Mount — the world-breaking part

sudo python3 mount.py mount /dev/sdb2 /data/games
python3 mount.py list

Your old disk appears at its new path with zero copy. Steam games launch immediately. Migration = a mount entry, not a copy.

Check the environment

python3 bootstrap.py doctor

Prints python + git locations and versions on any OS.
