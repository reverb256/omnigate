03The world-breaking ten

Researched and verified against real technology — systemd, QEMU, the Linux kernel. Each is a standard tool used as a separate program; nothing is vendored.

  1. Ghost Drive — old disk as a permanent zero-copy lower layer via Discoverable Partitions GUID rewrite. Migration = 0-second event.
  2. The Coffin — seal old /usr + /etc as a signed systemd-sysext image (DDI + dm-verity); the old OS runs as an app.
  3. Living Ghost VM — boot the old partition as a qcow2 backing file with virtiofs DAX (~20× faster, zero double-caching).
  4. Time-Travel Boot — hibernate the old OS (swsusp); resume it later in a VM, fork sessions, diff machines.
  5. The One-File Computer — the manifest captures state: Steam library, browser profiles, dconf, content-addressed hashes.
  6. Chunked-Time Machine — casync-style content-defined chunking (buzhash + SHA-512/256 + zstd); chunks dedupe across file boundaries.
  7. Process Resurrection — CRIU-checkpoint running apps; the OS changes underneath running applications.
  8. The Oracle — a pre-flight agent on the old machine: enumerate, clean re-downloadables, checksum, generate the plan. Fanotify keeps a live change journal during cutover.
  9. State Alchemy — semantic converters for app state: Steam saves, browser profiles, dconf, registry hives. Migrate meaning, not just files.
  10. Cross-OS Delta Feed — zsync/rdiff binary deltas over HTTP + IPFS/LAN seeding. Migrating N machines costs ~1 copy of the data.
