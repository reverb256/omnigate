01Three launchers, one tool

omnigate runs on the source machine on all three OSes — Windows and macOS included, not just as detection targets.

omnigate.sh

macOS / Linux

POSIX sh. Finds python3, delegates to bootstrap.py. Requires xcode-select --install on macOS (provides both python3 and git).

omnigate.ps1

Windows

PowerShell ships with Windows. Finds py -3 / python, delegates to bootstrap.py. Needs Git for Windows + Python (3.9+).

bootstrap.py

All three

Finds Python 3 + git, prints install instructions if missing, runs the command. Git is the backbone — every machine gets a repo of its migration state.

02Windows

powershell -ExecutionPolicy Bypass -File omnigate.ps1 --help
powershell -ExecutionPolicy Bypass -File omnigate.ps1 export --os windows --out my-setup.zip
powershell -ExecutionPolicy Bypass -File omnigate.ps1 doctor

# or straight through the py launcher (Python 3.9+ required)
py -3 bootstrap.py export --os windows --out my-setup.zip

Requirements: git (Git for Windows — default options put it on PATH) and Python (python.org, tick "Add python.exe to PATH", or the Microsoft Store app). bootstrap.py checks both and prints these links if either is missing.

03macOS

./omnigate.sh export --os macos --out my-setup.zip

Requirements: xcode-select --install provides both python3 and git; or install from python.org / brew install python git.

04Linux

./omnigate.sh export --os linux --out my-setup.zip
# or directly:
python3 bootstrap.py export --os linux --out my-setup.zip

mount.py is Linux-target only (overlayfs + root).
