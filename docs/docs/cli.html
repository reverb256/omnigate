01Entry points

Every command goes through bootstrap.py, which finds Python 3 + git and passes through exit codes.

./omnigate.sh <command> ...   # macOS / Linux wrapper
powershell -ExecutionPolicy Bypass -File omnigate.ps1 <command> ...   # Windows
python3 bootstrap.py <command> ...   # any OS

Exit codes: 0 success, 2 bad command/usage, 3 missing toolchain.

02Migrate

export

python3 migrate.py export --os linux --out my-setup.zip
python3 migrate.py export --os macos --out my-setup.zip
python3 migrate.py export --os windows --out my-setup.zip

Runs on the source machine. Detects installed apps, collects configs, and builds a git-committable package (machine.json, plan.md).

import

python3 migrate.py import my-setup.zip --dry-run
python3 migrate.py import my-setup.zip

Runs on the fresh Omarchy box. Maps to Omarchy targets (defer rule), runs the compat gate, ports configs, and generates a Home Manager profile fragment for Reverb-OS.

03Mount & ghost

sudo python3 mount.py mount /dev/sdb2 /data/games   # zero-copy union mount
python3 mount.py list                                    # show mounts
sudo python3 mount.py unmount <path>                     # tear down
sudo python3 mount.py ghost /dev/sdb2                   # permanent zero-copy lower layer

ghost rewrites each partition's GPT type GUID to the Discoverable Partitions Spec so systemd-gpt-auto-generator auto-mounts it forever. Rollback = boot the old ESP.

04Sync

python3 sync.py <src> <dst> --dry-run   # reflink-first differential sync

Copies only what changed; skips re-downloadable content. Reflink-first on btrfs/XFS means near-instant with zero duplicate space.

05Oracle

python3 oracle.py plan --dry-run --out plan.json
python3 oracle.py cleanup-plan --out cleanup.json

The pre-flight agent. Enumerates apps/profiles/caches, cleans re-downloadable content, checksums everything, and generates the complete plan as a reviewable artifact.

06TUI & doctor

python3 tui.py                    # terminal UI: command picker, plan review, progress bar
python3 tui.py --plan plan.json   # review a specific plan
python3 tui.py --src <dir> --dst <dir>  # live sync view
python3 bootstrap.py doctor       # prints python + git locations/versions

The TUI is box-drawn and ANSI-colored; it degrades to plain text when not a TTY. The plan review color-codes each action: green = copy, blue = defer, yellow = unknown.
