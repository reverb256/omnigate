01Rollback always

The default posture is that nothing is destroyed until you say otherwise.

Read-only mountsThe old disk is mounted read-only as an overlayfs lower layer. Nothing writes through to it.
Dry-run by defaultimport --dry-run and sync --dry-run show the plan before anything moves.
Old system stays bootableUntil you explicitly remove it, the old OS remains a boot option — dual-boot without dual-booting.
Ghost, not wipeghost rewrites GPT GUIDs for auto-mount; it never erases the source partition.

02Credential handling

Credentials are exported through a tiered path (creds.py) — with explicit consent, not silent collection. The manifest and git artifacts never carry live secrets.

  • Tiered credential export — only what you explicitly authorize.
  • No secrets in machine.json or plan.md.
  • Same-user, local-only tools. Nothing phones home.

03Deterministic runtime

The shipped tool makes zero LLM calls. AI is used to build it, never to run it. That means no prompt injection surface at runtime, no network calls to a model, no data leaving the machine. The tool works offline.

04What omnigate won't do

  • Won't auto-map an unknown app — it flags it for review.
  • Won't overwrite an existing config without a confirm.
  • Won't claim kernel-level anti-cheat can run on Linux — that wall is real and it's stated plainly.
  • Won't vendor code from a no-license repo (the one hard license rule).
