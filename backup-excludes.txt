# rclone exclude rules for zephyr /home/j_kro -> garage S3

# SYNTAX (rclone.org/filtering + fs/filter/filter.go Add()):
#   A bare name like ".bun" is a FILE rule ONLY. It matches a file named
#   ".bun" and does NOT exclude the directory's contents — rclone still
#   recurses in and copies everything. Excluding a directory REQUIRES
#   "dir/**" (or a trailing "/"). Leading "/" anchors to the source root.
#   Docs list this as pitfall: "Not using ** to match the contents of a
#   directory."
#
# Verify any change with:
#   rclone ls /home/j_kro --exclude-from backup-excludes.txt --dry-run | wc -l
